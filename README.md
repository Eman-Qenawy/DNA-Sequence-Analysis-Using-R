DNA Sequence Analysis Using R

Overview

This project presents an R-based bioinformatics analysis of two fungal strains derived from my Master's research:

- Yarrowia lipolytica — GenBank accession: PP666851
- Rhodotorula diobovata — GenBank accession: PP666850

The project focuses on nucleotide and protein sequence analysis and comparative analysis of the two fungal strains.

Objectives

- Analyze and compare nucleotide sequences.
- Perform protein sequence analysis.
- Assess sequence similarity between the two strains.
- Perform global sequence alignment.
- Investigate GC content variation across sequences.
- Present the analysis and results in an interactive HTML report.

Analysis Workflow

1. Sequence retrieval and preparation
2. Nucleotide sequence analysis
3. Protein sequence analysis
4. Sequence alignment
5. Similarity assessment
6. Sliding-window analysis of GC content
7. Visualization and interpretation of results
8. Generation of an interactive HTML report

Tools & Technologies

- R
- RStudio
- Sequence analysis
- Global alignment
- Protein sequence analysis
- GC content analysis
- Data visualization
- HTML reporting

Results

The project provides an interactive report containing the analysis, visualizations, and results generated from the sequence data.

Project Output

The main output is an interactive HTML report integrating the analysis, code, and results to support reproducible bioinformatics research.
